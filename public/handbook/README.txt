วิธีเปิด
- เปิด index.html ด้วย Chrome หรือ Edge ได้โดยตรง
- ถ้าเปิดเว็บโปรเจกต์อยู่ เข้า http://localhost:3000/handbook/index.html
- เก็บ index.html, handbook.css, handbook.js และ assets ไว้ด้วยกัน
- รูปและฟอนต์อยู่ใน assets จึงอ่านคู่มือแบบออฟไลน์ได้

วิธีนำเสนอ
- กด “โหมดนำเสนอ” เพื่อแสดงทีละหัวข้อ
- ใช้ลูกศรซ้าย/ขวา หรือ Page Up/Page Down เพื่อเปลี่ยนหัวข้อ
- Home ไปหน้าแรก, End ไปหน้าสุดท้าย, Esc กลับโหมดอ่าน
- กด “พิมพ์ / PDF” เพื่อพิมพ์ทุกหัวข้อเป็น A4 แนวนอน
- แนะนำเปิด Background graphics และปิด Headers and footers ในหน้าพิมพ์
